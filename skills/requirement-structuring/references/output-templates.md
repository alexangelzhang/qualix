# 输出模板

## 边界约定（Boundaries）

在报告末尾输出三级边界约定，供 Phase Q02/Q05/Q06/Q07 引用：

```markdown
## 边界约定

### 必须做（Always）
- 所有金额计算使用 BigDecimal，精确到分
- 所有写操作必须有幂等保护
- ...（从 SE 中提取的强制约束）

### 需确认（Ask First）
- 是否需要支持批量操作（PRD 未明确）
- 退款是否需要审批流程（OPEN-003）
- ...（从 GAP/OPEN 中提取的待决策项）

### 禁止做（Never）
- 不在本次范围内的模块不改动
- 不引入新的外部依赖（除非技术方案明确要求）
- ...（从需求范围推导的排除项）
```

> **为什么需要边界约定**：下游 Phase 看不到 Phase Q01 的完整上下文，只看结构化产物。
> 边界约定让约束显式化，防止下游 Agent 各自猜测。

## 范围外发现（Noticed But Not Touching）

如果在结构化过程中发现了超出本次需求范围的问题，记录但不处理：

```markdown
## 范围外发现
- [代码] 现有订单表缺少 version 字段，无法支持乐观锁（与本次需求无关但影响并发安全）
- [需求] 相邻模块"结算"的状态机与本次"定损"有交互，但不在本次范围内
```
