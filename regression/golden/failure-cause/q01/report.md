## 关键语义（SE）

| SE | 类别 | 描述 |
|----|------|------|
| SE-001 | 幂等/并发 | 并发创建同名故障原因只允许一个成功 |
| SE-002 | 状态迁移 | 最后一个有效关系置无效时底表状态自动变无效；恢复有效时底表恢复 |
| SE-003 | 状态迁移 | 两层状态修改不联动（各自独立） |
| SE-004 | 状态边界 | 取消品类：有审核中数据拦截；全无效可取消 |
| SE-005 | 业务约束 | SKU互斥不仅是前端置灰，服务端也应拦截 |
| SE-006 | 灰度/路由 | 灰度内外查询逻辑不同，按品类+机构维度路由 |
| SE-007 | 系统限制 | 批量导入≥5001条时系统拦截 |
| SE-008 | 业务约束 | 故障类与非故障类互斥，系统级拦截 |
