## 业务规则

| ID | 规则 | 业务后果 | 来源 |
|---|---|---|---|
| BR-001 | 报价单、到店工单、移动工单添加服务项时，依据配件主数据“小数出库=是”支持小数输入和展示。 | 防止小数配件仍按整数使用，导致工单用量错误。 | `prd.md:139` |
| BR-002 | 小数配件数量单位到小数点后两位。 | 防止展示或计算精度丢失。 | `prd.md:139` |
| BR-003 | 加减按钮步长固定为 1，默认值仍为 1，不使用 0.01 步进。 | 防止交互步长与业务确认不一致。 | `prd.md:139` |
| BR-004 | 预授权纳入编辑小数配件范围，并区分工单入口和质量技术入口创建。 | 防止预授权入口漏改或来源混淆。 | `prd.md:130` |
| BR-005 | 服务行动和服务项组套入口支持小数配件编辑。 | 防止后台配置类入口仍无法处理小数配件。 | `prd.md:143` |
| BR-006 | 押金特殊配件维修编辑延期到二期。 | 防止一期误上线二期能力。 | `prd.md:142` |
| BR-007 | 报价单展示小数配件数量到两位小数。 | 防止报价单数量被取整。 | `prd.md:151` |
| BR-008 | 工单在零售通 PAD 和售后工作台均展示小数配件数量。 | 防止不同端展示不一致。 | `prd.md:152` |
| BR-009 | 退款、索赔/预授权、服务行动、车辆档案展示小数配件数量。 | 防止相关页面链路丢失小数位。 | `prd.md:153` |
| BR-010 | 押金特殊配件维修+提前交车展示延期二期。 | 防止一期范围污染。 | `prd.md:157` |
| BR-011 | 工单退款数量不得超过工单配件使用数量，即最大可退数量。 | 防止超退。 | `prd.md:139` |
| BR-012 | 支持小数且使用数量为小数时，仅允许全额退款并禁用数量修改。 | 防止小数配件被部分退款导致账实不一致。 | `prd.md:139` |
| BR-013 | 支持小数但使用数量为整数时，维持现有部分整数退款逻辑。 | 防止兼容场景被误伤。 | `prd.md:139` |
| BR-014 | 添加小数配件时前后端都校验配件单价是否为整数。 | 防止绕过前端提交非法配件。 | `prd.md:139` |
| BR-015 | 单价含小数的配件拦截文案必须包含相关配件名称，多个配件用顿号连接。 | 防止用户无法定位需运营修正的配件。 | `prd.md:139` |
