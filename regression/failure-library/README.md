# Public Failure Library

This directory contains only synthetic or sanitized examples that are safe to publish.

Real enterprise failure libraries, customer requirements, bug imports, and private review data should stay outside the public repository. Qualix can still read user-local cases from `~/.qualix/regression/failure-library/` during normal use.

The public seed cases also back the [phase failure patterns benchmark](../../benchmarks/phase-failure-patterns/README.md), which groups examples by the Qualix phase that failed to preserve, expand, or audit a business semantic.
