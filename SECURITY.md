# Security Policy

## Supported Versions

Qualix is currently in public alpha. Security fixes are applied to the `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities or accidental private-data exposure.

Report privately by emailing the maintainer listed on the GitHub profile, or by opening a minimal GitHub issue that says you have a security report to share without including sensitive details.

Please include:

- Affected version or commit.
- Reproduction steps.
- Impact assessment.
- Any logs or artifacts with secrets and private data removed.

## Data Safety

Qualix workflows can process requirements, designs, review reports, and failure cases. Public contributions must not include real customer requirements, internal links, credentials, access tokens, or private enterprise failure-library data.
