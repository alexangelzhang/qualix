# Results

Benchmark runs write JSON files here, one per `run_benchmark.py` invocation.

## What lives here

- `<provider>-<model>-<UTC-timestamp>.json` — auto-generated by `run_benchmark.py`
- Files written here are local to the developer's machine. They are not committed.

## Why not committed

Two reasons:

1. **Cost-noise**: every commit would otherwise embed a paid API call, and re-running on a different week would produce a slightly different file even with `temperature=0`.
2. **Comparability**: results are only meaningful when paired with the prompt hash. Storing them in-repo encourages stale comparisons.

The repository's `.gitignore` should exclude `results/*.json` (verify before adding new commits). The `.gitkeep` file in this directory is the only tracked file.

## Sharing a result

If you want to share a benchmark run, paste the JSON into an issue, a PR description, or a separate `benchmark-results` repository. Do not commit it here.
