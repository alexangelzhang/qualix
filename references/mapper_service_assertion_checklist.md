## A. 分层职责一致性（DDD + TMF）

### A1. DDD 分层职责

- [ ] Client 层仅承载接口契约/DTO，无业务分支。
- [ ] Application 层仅负责编排、转换、异常包装，无核心领域规则。
- [ ] Domain 层覆盖聚合根不变式、状态迁移、幂等/并发等核心规则。
- [ ] Infrastructure 层仅承载 Gateway/Mapper/RPC/DB 技术实现。
- [ ] 通过用例证明“核心业务规则不在 Application 层实现”。

### A2. TMF 分层职责

- [ ] DomainService 存在 `decideSteps + TMF.execute` 正向路径用例。
- [ ] DomainService 存在 `TMF.execute` 失败路径与业务后果断言。
- [ ] Step 通过 `TMF.findAbility()` 调用 Ability（无 `@Resource/@Autowired` 直接注入 Ability）。
- [ ] Ability 继承 `AbstractDomainAbility<Model, Extension>` 并覆盖核心调用路径。
- [ ] 扩展点调用模式与业务一致（`firstExtension` 或 `Reducer.allOf`）。

## B. Mapper/Gateway 层（写操作）断言

### B1. 插入/更新结果正确性

- [ ] 断言受影响行数符合预期（1/0/批量条数）。
- [ ] 断言主键生成/回填正确。
- [ ] 断言创建时间字段正确写入。
- [ ] 断言更新时间字段在更新后变化正确。
- [ ] 断言本次新增字段已正确持久化。
- [ ] 断言关键业务字段值准确（不是仅 `not null`）。

### B2. 数据一致性与约束

- [ ] 断言唯一键冲突场景行为正确。
- [ ] 断言非法枚举/非法状态入库被拒绝。
- [ ] 断言字段长度溢出被拒绝或截断策略符合需求。
- [ ] 断言必填为空时行为符合需求（抛错/拦截）。
- [ ] 断言并发写入语义正确（无重复写/脏写）。

## C. Application/CmdExe 层断言

### C1. 编排与转换

- [ ] 断言 `Command/DTO -> Domain` 映射正确。
- [ ] 断言 `Domain -> Response` 映射正确。
- [ ] 断言异常包装策略正确（包装/透传/错误码映射）。
- [ ] 断言主流程不依赖“仅调用次数”作为通过条件。

### C2. TMF 适配（若适用）

- [ ] 断言 `CustomModelAbility.render` 触发条件与结果。
- [ ] 断言 TMF 链路失败时返回/抛出符合需求语义。

## D. Domain/Step/Ability 层断言

### D1. Domain 规则

- [ ] 至少 1 条主成功路径覆盖核心领域规则。
- [ ] 覆盖状态迁移合法/非法路径。
- [ ] 覆盖幂等语义（重复请求无额外副作用）。
- [ ] 覆盖事务语义（回滚/补偿行为符合预期）。

### D2. Step 断言（TMF）

- [ ] `process()` 主路径覆盖。
- [ ] `invokeStep(...)` 顺序与条件正确。
- [ ] `rollback()`（如定义）触发条件与结果正确。
- [ ] Step 失败后链路中止语义正确。

### D3. Ability 与扩展点断言（TMF）

- [ ] `firstExtension()` 路径覆盖（单扩展点场景）。
- [ ] `getExtension(..., Reducer.allOf())` 路径覆盖（多扩展点场景）。
- [ ] `defaultExtension()` 有/无默认实现两类路径覆盖。
- [ ] 扩展点缺失、扩展点抛错、降级策略有断言。

## E. 关键语义（SEM）覆盖（新增）

- [ ] 已抽取关键语义 `SEM` 并映射到 `REQ/BR`。
- [ ] 每条关键语义至少 1 条“规则正确性”UT。
- [ ] 每条关键语义至少 1 条“边界/稳定性”UT（重复执行/冲突输入/乱序输入）。
- [ ] 关键语义规则有可验证证据（排序键/去重键/状态守卫/窗口边界）。

### E1. 图片语义专项（有图示时必填）

- [ ] 图片中的流程/状态/口径规则已转为 `SEM`。
- [ ] 图片语义已映射到 `DESIGN/CODE/UT/EUT`。
- [ ] 图片语义未解析项已标注风险并安排人工补录。

## F. 异常与边界（强制）

- [ ] 覆盖字段长度溢出。
- [ ] 覆盖必填为空（null/blank）。
- [ ] 覆盖枚举非法值。
- [ ] 覆盖数值越界（负值/超上限/精度）。
- [ ] 覆盖状态非法迁移。
- [ ] 覆盖第三方超时/失败/异常返回。
- [ ] 覆盖异常时间格式/非法时区/格式截断（格式边界 mock）。
- [ ] 覆盖并发冲突（锁竞争/重复提交）。
- [ ] 覆盖配置缺失/错误（开关/路由/步骤链）。

## G. 异常后果断言（仅抛异常不算通过）

- [ ] 断言异常类型/错误码/错误信息（至少一项稳定断言）。
- [ ] 断言失败后状态未被错误推进。
- [ ] 断言数据库无脏写/无重复写/无半成功。
- [ ] 断言事务回滚或补偿行为符合预期。
- [ ] 断言幂等行为正确（重复请求无额外副作用）。
- [ ] 断言 TMF 失败后链路中止与回滚/补偿语义正确。

## H. 覆盖率门禁（增量口径）

- [ ] 增量分支覆盖率 >= 80%。

- [ ] 对外 API / 第三方格式依赖代码：行+分支覆盖率 = 100%。
- [ ] TMF 关键编排节点（decide/execute/ability）正反路径均覆盖。
